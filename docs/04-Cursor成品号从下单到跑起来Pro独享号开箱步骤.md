# Cursor 成品号从下单到跑起来：Pro 独享号开箱步骤

![](https://cdn.laoshoucun.com/web/2026/10/cursor-cover-v4-pro-20261010.jpg)

第一次买这类账号，最慌的不是付款那一刻，是拿到账号之后不知道下一步点哪。我第一次也是，盯着登录页发了两分钟呆。这篇把整条路走一遍。

## 下单之后会看到什么

付款完成，页面要么直接给出账号，要么显示正在发货中。我第一次拿到的是自动发货的档，付款当场就发号，想开工不用等。人工发货的档会给出客服的联系方式，加过去说一声就行，不会用也能直接问。

发过来的就两样，邮箱和登录密码。建议先复制到本地文本里存着，开着页面往下走进易手忙脚乱。

## 第一次登录

打开 cursor.com，点右上角登录，把邮箱和密码填进去。注意这里是登录不是注册，走到注册流程上是白折腾。

有些账号第一次登录会多走一步确认，页面提示什么就照着做完，通常一分钟不到。

## 登录之后先看两样东西

进去第一件事是看账户设置里的档位对不对，显示 Pro 就对了。然后去设置里把从 VS Code 导入点一下，插件，快捷键，主题都能带过来，界面基本不用重新认。

## 最容易出错的几个地方

一是浏览器里还挂着别的 Cursor 账号的登录状态，切换的时候容易串号，开个干净窗口就不会串。二是在多个设备上同时登录，独享号这么干会直接掉线。我第一次就是第二条踩了坑，手机上顺手登了一次，电脑那边立刻掉线。

## 想自己走一遍

顺便说下这条路为什么有人走。官网那边要一张外币卡，账单地址还得对得上，两道都过了才付得出去。成品号把这两道绕开了，账面上也比在官网订省一点。
