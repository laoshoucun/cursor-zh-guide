# Cursor 可以只订阅一个月吗？Pro 代订阅的两条路径

![](https://cdn.laoshoucun.com/web/2026/10/cursor-cover-v4-pro-20261010.jpg)

朋友问我能不能只买一个月，不想签长期。答案是可以，拿到的方式有两种，选错会绕远路。

## 两条路径的分叉点

第一条是自己去官网订阅一个月，到期停掉。这条路账号完全属于自己，但要走通官网的支付和地址流程，外币卡那一关不少人过不去。

第二条是代订阅，用你自己已经注册好的账号，由服务方把它升到 Pro，一个月之后回到基础档。

两条路的账期一样，差别在操作方式。对已经有账号的人来说，第二条少折腾。

## 代订阅具体怎么走

流程比想象的短。在站内下单，付款之后页面会提示正在发货中，同时给出客服的联系方式。加过去，把账号给到对方，等处理完，回官网刷新一下档位就变了。

你不需要换号，不需要重新登录别的东西，也不需要搬数据。升级完成之后，历史对话，项目，配置原样都在。

## 为什么老用户偏爱第二条

用得越久，账号里的东西越多。三个月前排查并发问题的那段对话，你后来补的一条条规则，后台那条用量曲线，这些都是拿时间换来的。换号等于把这些扔掉。所以对一个已经用了很久的人来说，代订阅的价值不是图方便，是不丢东西。

## 一个月到期之后

账号回到基础档，历史和数据不受影响。想继续用可以再拍一次，或者那个时候再看要不要换成长周期。有一点要说明，额度奖励按官方随机档位走，具体口径以 cursor.com 页面为准。

## 想走代订阅怎么走

官网那条路要先解决外币卡，这一关不少人过不去，这也是第二条路存在的原因。花销上从这边走比官网订低，账户还是自己那个。

我朋友最后走的就是老手村的代订阅，账号给过去，一个月档当天就办好，他账号里存着大半年的项目记录，所以没选换号那条。想给自己的号升一档的，自己去微信上加 douhanq 问一句就行。
