## Cursor 是什么

Cursor 是全球主流 AI 代码编辑器，官网 cursor.com，支持 Tab 补全、Ctrl+K 就地改代码与 Agent 自动编码。它的会员分 Pro（$20/月）、Pro+（$60/月，3 倍额度）、Ultra（$200/月，20 倍额度）与 Team（$40/用户/月）四档，官网订阅需要外币卡、账单地址也要对得上，所以国内不少人走「成品号」、「代订阅」或按批买号这条路。本仓库收录的 20 篇文章，把 Cursor 速刷号到底是什么意思、Cursor Pro 成品号怎么用、Cursor Pro 月卡划不划算、Cursor 代订阅和成品号差在哪、Pro+ 与 Ultra 的额度该怎么算这些问题逐条讲清楚，全部是第一人称实测与答疑口吻，不写成广告；批量与批发场景下号、密码、档位、到期时间怎么一一对上，也单独交代了。

## Cursor 账号有哪几种形态

| 形态 | 说明 | 常见时长 |
| --- | --- | --- |
| **Cursor 速刷号** | 已开好会员的成品号，价格最低，按天算，到期即止，不续期，无售后质保 | 3 天 |
| **Cursor 成品号** | 独享账号，付完发邮箱与登录密码，到 cursor.com 官网直登，登录后即为对应档位 | 3–30 天 |
| **Cursor 月卡** | 25–30 天有效期，适合长期日常使用，是成品号的按月形态 | 25–30 天 |
| **Cursor 代订阅** | 把**你自己已有**的 Cursor 账号升级到对应档位，账号、数据、插件配置都不变 | 25–30 天 |

## Cursor 账号批发与批量购买

搜「Cursor 账号批发」的人，通常不是自己用一个号：要么一个人要在台式机、笔记本、服务器上各配一套，要么一次要给几个同事、学员或客户配号。这个场景跟买单个号不是一回事，先把几件事说清楚。

| 批量场景 | 常见做法 | 要注意的 |
| --- | --- | --- |
| 一人多设备 | 一个成品号在多台设备登同一账号 | 同一账号多设备并发有上限，别几台机器同时跑 Agent |
| 小团队每人一个号 | 按人头发独立成品号 | 要共享同一套规则与用量管理就用 Team 档，不是多买几个 Pro |
| 给学员 / 客户配号 | 按批次发号、逐条对应 | 收到号第一件事是核对档位与到期时间，不是先装编辑器 |

批发与零售真正的差别不在价格，在**交付形态**：单个买是一个号配一个邮箱密码发过来；按批买的核心是**号、密码、档位、到期时间能一一对上**，发下来能直接登、能核对、出问题能定位到是哪一条。所以批量通常走**成品号**或**月卡**（各有独立账号），而不是代订阅——代订阅是把你自己已有的号升级，一个号一个号做，不适合按批下发。

按批买之前，有三件事值得先谈清楚：一次要几个号、要统一档位还是混合档位、号是一次性给清单还是边发边核。这几条说明白了，后面才不会对不上账。批量场景要问的，微信上加 douhanq 说一句就行。

## Cursor 档位对照

| 档位 | 官方月费 | 额度定位 | 什么人在用 |
| --- | --- | --- | --- |
| **Cursor Pro** | $20/月 | 基础档，无限 Tab 补全 + Agent 扩展额度 + 全部前沿模型 | 日常写代码，只用 Tab 的基本用不完 |
| **Cursor Pro+** | $60/月 | Pro 的 **3 倍**额度 | 天天跑 Agent，Pro 额度经常见底 |
| **Cursor Ultra** | $200/月 | Pro 的 **20 倍**额度（约 $400 模型额度） | 同时跑多个 Agent、大项目并行 |
| **Cursor Team** | $40 起/用户/月 | 团队协作 + 管理功能 | 小团队共享一套工作流 |

> 官方口径的用量参考：只用 Tab 的用户基本用不完 Pro 额度；天天跑 Agent 的用户月用量约 $60–$100；同时跑多个 Agent 的重度用户常在 $200 以上。
